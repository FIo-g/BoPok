이동주의 공유 DB 적용 요청에 따라 PR #29가 머지된 main `66c9d5d3e8d12f5effd1b3555e53b7eb371e9aef`의 코드와 마이그레이션으로 Neon에 반영했다. 추가 관광정보 조사는 하지 않았다. DB 적용 단계에서는 제품 코드 변경이나 commit/push/merge를 하지 않았으며, 이 보고서는 후속 문서 PR로 공유한다.

## 실행 및 검증

- 기존 장소·구간·마이그레이션 이력을 먼저 로컬의 무시된 디렉터리에 백업했다.
- main 전용 분리 작업 폴더에서 `0005_place-services-research`를 적용했다. 마이그레이션 이력은 5개에서 6개로 늘었다. SQL SHA-256은 `81a72d4980dd9b619b602cedf069e25d2ed4d28824a444aac63fca7cf66882eb`이다.
- 자료 매핑과 원본 파일 해시를 확인한 뒤 승인된 입력 스크립트를 실행했다. 조사 자료는 장소 72곳과 근거 17,468건을 추가했으며 기존 장소 3곳에 연결했다. 기존 요약 필드 업데이트는 0건이다.
- 조사 자료를 다시 실행한 결과 장소 추가·업데이트·근거 추가가 모두 0건이고 근거 17,468건이 그대로 재사용됐다.
- 서비스 카탈로그는 첫 실행에서 원본 레코드 20,206건을 입력했고 재실행에서 추가 0건, 동일 레코드 20,206건을 확인했다.
- 실제 공유 DB에서 식당·카페·숙박 추천이 종류별로 정상 반환되는 것을 확인했다. 현재 검색 방식은 `keyword`다.
- 식당·카페 20,000곳의 착석 기본값을 확인했다. 현장 좌석 검증을 의미하지 않으며, 빈 음식 주의 태그는 확인되지 않은 상태로 유지한다. 실제 메뉴와 메모리 안의 가상 건강 프로필로 검증한 주의 안내 상태는 `no_menus`다.
- 가격 조회 표본 4곳을 확인했고, 단위를 모르는 메뉴는 미확인 단위로 유지했다.
- 실제 배포 사이트 `https://bopok.vercel.app/api/places?kind=종류&limit=3`에서 `attraction`, `restaurant`, `cafe`, `lodging` 네 종류 모두 HTTP 200과 새 장소 응답을 확인했다.
- 배포 사이트 첫 화면은 브라우저로 확인했다. 여행 편집 화면은 로그인이 필요해 이번 세션에서 확인하지 못했다.
- 배포 전 승인된 코드 검증: lint, vitest 112개 파일·1,735개 테스트, 타입 검사 및 production build 통과. 이번 DB 적용 중 제품 코드 변경은 없다.

## 보류와 적용 범위

조사 후보 108곳 중 33곳은 미매칭 26곳, 부분시설만 매칭 4곳, 상위시설만 매칭 2곳, 중복 범위 1곳으로 장소 연결을 보류했다. 보류 후보의 조사 기록은 남겼다. 별도 격리 자료 39건도 원래 상태로 보존했다.

부분시설·상위시설의 자료를 전체 관광지의 확정 정보로 승격하지 않았다. 후보 108곳 모두 연속 휠체어 접근성이 미확인이며, 조사 좌표를 검증된 입구나 보행 그래프로 간주하지 않았다. 미확인 정보를 계단 없음·식단 안전으로 변환하지 않았다.

## 남은 작업

pgvector 스키마와 인덱스는 준비했다. 현재 로컬 설정에 `UPSTAGE_API_KEY`가 없어 임베딩은 0건이며 실제 벡터 검색은 아직 검증하지 않았다. 유효한 Upstage 키로 작은 배치를 검증하고 종류별 전체 인덱싱을 마친 뒤 실제 벡터 검색을 검증해야 한다.

배포 사이트 로그인 후 여행의 `직접 고치기` → `+ 장소 더하기`에서 종류별 목록을 확인하는 화면 검증이 남아 있다. 출처가 확인되지 않은 음식 주의 태그·가격 단위·접근성 범위는 계속 미확인으로 취급한다.

AI 기본 일정 후보는 관광지로 한정돼 있다. 사람이 고른 식당·숙박을 보존하는 동작과 종류별 추천은 구현됐으나, 방문 동선에 맞는 식당·숙소를 AI 일정에 자동 배치하는 연결은 후속 작업이다. 비용 직접 입력의 서버 저장·가족 공유도 별도 범위 결정이 남았다.

상세 실행 영수증과 백업은 `.pglite/shared-db-20261104/`에 로컬 보관한다. 인증정보·DB 접속 문자열·실제 사용자 정보는 이 보고서에 포함하지 않았다.
