# 이동주 담당 마무리 기록 — 2026-11-04

작업 브랜치: `geo/cost-sharing-20261104`. 최신 팀 main `725515d`를 기준으로 작업 변경을 보존해 재적용했다. 사용자 요청에 따라 이 브랜치의 기능을 커밋·push한다. PR 리뷰·머지와 새 비용 테이블의 공유 DB 적용·배포는 이후 단계다.

## 종료 시점 결과

- 확보된 카탈로그 20,206곳의 벡터 색인을 완료했다. 관광지 184곳·숙박 22곳과 식당 17,513곳·카페 2,487곳이 대상이다. 마지막 재개 작업은 15,697건·982회 요청·실패 0회였으며, 남은 색인 대상이 없어서 정상 종료했다. 원문·모델이 같은 항목은 건너뛴다.
- 실제 관광지·숙박 벡터 검색과 배포 화면의 숙박 의미 검색을 확인했다. 식당·카페 색인 완료 후 추가 실제 검색 검사는 사용자 요청에 따라 생략했다.
- 전체 114개 파일·1,753개 테스트가 통과했다. 이후 최신 팀 main을 반영하고 린트·배포 빌드도 통과했다. 최신 main 통합 후의 전체 테스트 재실행은 사용자의 검사 중단 요청으로 중단했으며 통과로 기록하지 않는다.
- 사용자 요청에 따라 추가 검사를 종료했다. 이어진 커밋·push 지시에 따라 작업 브랜치를 공유한다. 새 비용 마이그레이션의 공유 DB 적용, PR 머지·배포는 하지 않았다.

## 배포 사이트에서 확인한 것

- 기존 관광지·식당·카페·숙박 자료가 장소 선택 창에 표시된다. 식당·카페에는 실제 메뉴·가격과 출처·확인일·신뢰 등급이 표시된다.
- 숙박 검색어 `대전에서 가족과 머물 숙소`에서 “의미가 가까운 순으로 검색했어요”와 실제 숙소 후보를 확인했다. 배포 환경에서도 Upstage 벡터 검색이 작동한다.
- 점심 1인 금액 10,000원을 입력해 10,000~12,000원으로 계산되고, 다른 미확인 항목은 합계에서 제외되는 것을 확인했다. 확인 후 임시 입력을 초기화했다.
- 기존 사용자 여행을 저장·확정·재생성하지 않았다. 검사 중 열었던 직접 편집은 취소했다.

## 새로 구현한 것 — 배포 전

- 비용 저장: 여행 버전·일차별 명시적 저장과 같은 가족 그룹의 조회·수정. 저장 당시 일정·인원과 달라지면 자동 적용하지 않는다. revision 조건부 갱신으로 다른 가족의 저장본을 덮어쓰지 않는다.
- API: `GET/PUT /api/trips/:id/versions/:vid/costs`. 미인증·다른 그룹 접근을 차단한다. 금액·단위가 비어 있는 초안은 미확인 상태 그대로 저장한다.
- 추가형 SQL `drizzle/0006_trip-cost-plans.sql`: 공유 DB에 적용하지 않았다. 테이블이 아직 없으면 기존 계산은 유지하며 저장 준비 중으로 안내한다.
- AI 동선 연결: 빈 식사·카페·숙박 자리만 같은 날 동선 주변의 등록 장소로 채운다. 처음부터 만드는 여러 날 일정에는 마지막 날 전까지 숙박 자리를 추가한다. 직접 선택·예약·꼭 갈 곳은 보존한다.
- 피할 음식 태그가 메뉴에서 확인된 후보는 자동 배치에서 제외한다. 미확인 태그·좌석·영업·숙박 가격·접근성은 추정하지 않는다.
- 벡터 입력 도구에 종류별 색인을 추가하고, 한 배치를 한 SQL로 저장한다. 원문·모델이 같으면 재실행 시 외부 API 호출 없이 건너뛴다.

정책은 `docs/superpowers/specs/2026-11-04-cost-sharing.md`, `2026-11-04-route-services.md`에 기록했다.

## 로컬 화면·API 검증

별도 PGlite와 가짜 가족 계정 두 개를 사용했다. 실제 가족 데이터·공유 DB에는 새 비용 자료를 쓰지 않았다.

- 공동 점심값 30,000원 / 일행 2명 → 1인 15,000~18,000원.
- 비용 저장 후 새로고침해 같은 금액이 복원됨.
- 다른 가족 계정으로 로그인해 같은 금액과 저장자 표시를 조회함.
- API 테스트: 가족 조회·수정, 다른 그룹 403, 미인증 401, 버전·일차 분리, 동시 저장 충돌 409, 잘못된 항목·금액 거절, 인원·일정 변경 보존, 마이그레이션 전 대체 안내.
- AI 테스트: 같은 날 동선, 먼 후보 제외, 종류 확인, 중복 방지, 예약·직접 선택 보존, 여러 날 숙박, 조회 실패 대체, 확인된 식단 주의 태그 제외.

화면 증거와 인증값 없는 실행 결과는 로컬의 무시된 `.pglite/shared-db-20261104/`에 보관했다.
